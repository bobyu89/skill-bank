# Skill Bank

SKILL 收藏庫，依功能與用途分類。每個 SKILL 存在 `skills/<分類>/<skill-name>/SKILL.md`。

**找 SKILL 的方法**：在本頁用 Ctrl/Cmd + F 搜尋關鍵字（用途、觸發情境、標籤都會列在表格裡），或直接瀏覽下方分類。

## 分類總覽

| 分類 | 收什麼 | 數量 |
|---|---|---|
| [研究／學術](#研究學術-research-academic) | 文獻搜尋、論文寫作、APA、統計、EBP、報告指引、同儕審查 | 0 |
| [臨床／護理](#臨床護理-clinical-nursing) | 臨床照護、護理紀錄、個案報告、考試與臨床教學 | 0 |
| [技術／開發](#技術開發-tech-dev) | 程式開發、AI/Agent、MCP、自動化、資料分析 | 0 |
| [創意／設計](#創意設計-creative-design) | 插畫、視覺設計、簡報、品牌、影像 prompt | 0 |
| [寫作／溝通](#寫作溝通-writing-communication) | 一般寫作、電子報、內部溝通、語氣潤飾、翻譯 | 0 |
| [效率／工作流](#效率工作流-productivity-workflow) | 筆記、知識管理、排程、文件格式處理 | 0 |
| [思考／學習](#思考學習-thinking-learning) | 批判思考、學習方法、哲學、決策框架 | 0 |
