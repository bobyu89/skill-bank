## 一、台灣研究倫理審查（IRB 對應）

### 1.1 台灣 IRB 架構

```
台灣研究倫理審查體系：

人體研究法（2011年施行）
  └─ 人體研究倫理審查委員會（IRB / 研究倫理委員會 REC）

審查類型：
├─ 免審（Exempt）
│     → 公開資訊、去識別化次級資料分析
│     → 仍需向 IRB 申請免審認定
│
├─ 簡易審查（Expedited Review）
│     → 最小風險研究（問卷、訪談、觀察）
│     → 通常 2-4 週核准
│
└─ 一般審查（Full Board Review）
      → 涉及弱勢族群、侵入性程序、敏感議題
      → 需出席委員會報告，約 1-3 個月

⚠️ 護理研究常見情境：
  → 問卷調查護理人員 → 通常「簡易審查」
  → 訪談病患經驗 → 可能「一般審查」（弱勢族群）
  → 使用病歷回溯資料 → 需確認是否符合免審條件
```

### 1.2 台灣 IRB 申請文件清單

```
申請文件（依各校 IRB 略有差異）：
□ 人體研究計畫申請書
□ 研究計畫書（含研究目的、方法、預期效益）
□ 知情同意書（Informed Consent Form, ICF）
□ 受試者招募廣告/公告（若有）
□ 問卷/訪談大綱（研究工具）
□ 研究者利益衝突聲明
□ 指導教授同意函
□ 研究者倫理訓練完訓證明（CITI Program 或台灣研究倫理課程）

知情同意書必備要素（台灣版）：
□ 研究計畫名稱
□ 計畫主持人姓名與聯絡方式
□ 研究目的與方法說明（白話文）
□ 「您的參與完全自願，可隨時退出，不影響您的任何權益」
□ 資料保密與去識別化說明
□ 研究可能的風險與不適
□ 研究倫理審查委員會聯絡方式
□ 受試者簽名欄 + 日期
```

### 1.3 台灣常見 IRB 單位

| 機構類型 | 代表性 IRB |
|---------|-----------|
| 醫學中心 | 長庚 IRB、台大 REC、北榮 IRB |
| 大學 | 各校研究倫理中心（如：國北護 REC） |
| 聯合 IRB | 人體研究倫理審查委員會聯合認證 |

## 二、國科會（NSTC）計畫格式

### 2.1 研究計畫書架構

```
國科會專題研究計畫（NSTC，原 MOST）格式：

一、摘要（中英文各 500 字以內）
二、研究動機與目的
    → 臨床問題 → 文獻缺口 → 研究必要性
三、文獻探討
    → 理論基礎
    → 國內外相關研究（需包含台灣本土文獻）
四、研究方法
    → 研究設計
    → 研究對象與抽樣
    → 研究工具（含信效度）
    → 資料收集程序
    → 資料分析方法
    → 研究倫理
五、預期完成之工作項目及成果
六、參考文獻
七、經費需求表

⚠️ 注意事項：
  → 頁數限制：通常 12-15 頁（不含參考文獻）
  → 格式：A4、12pt 標楷體或新細明體、行距 1.5 倍
  → 預算需合理對應研究方法（如：逐字稿謄寫費、量表授權費）
```

## 三、碩士論文口試準備

### 3.1 口試委員常見提問

```
研究設計類：
Q1：為什麼選擇混合方法而非單一方法？
    → 說明質量互補的必要性，引用 Creswell
Q2：樣本數如何決定？統計考驗力足夠嗎？
    → G*Power 計算結果 + 效應量依據
Q3：你的量表是否經過中文化驗證？
    → 說明翻譯流程（back-translation）與 pilot test

分析方法類：
Q4：為什麼用 SEM 而不是多元迴歸？
    → 潛在變項需測量模型、可同時估計多路徑
Q5：質性編碼的可信性如何確保？
    → Member checking + 同儕詰辯 + 研究日誌
Q6：混合方法的整合點在哪裡？
    → 明確指出在設計/分析/詮釋哪個層次整合

研究限制類：
Q7：橫斷面設計如何推論因果？
    → 承認限制 + 建議未來縱貫研究
Q8：樣本代表性？能推論到其他醫院嗎？
    → 說明 transferability（質性）或外在效度限制
Q9：AI 工具發展快速，你的研究結果有時效性嗎？
    → 承認 + 強調框架/方法論的持續價值
```

### 3.2 口試簡報架構建議

```
碩士論文口試簡報（建議 20-25 分鐘）：
1. 研究背景與動機（3 min）
   → 臨床問題 → 文獻缺口 → 研究必要性
2. 研究目的與問題（2 min）
   → RQ1, RQ2... 清晰列出
3. 文獻探討重點（3 min）
   → 只呈現核心理論與關鍵文獻，不要全部唸
4. 研究方法（5 min）
   → 研究設計圖（視覺化）
   → 樣本、工具、分析方法
5. 研究結果（7 min）
   → 量性：關鍵統計表格
   → 質性：主題架構圖 + 代表性引文
   → 整合：Joint Display
6. 討論與結論（3 min）
   → 與文獻對話
   → 臨床實務意涵
7. 研究限制與未來建議（2 min）
```

## 四、台灣常用研究量表

### 4.1 科技接受度相關

| 量表 | 原始作者 | 中文版本 | 適用情境 |
|-----|---------|---------|---------|
| TAM（科技接受模式） | Davis (1989) | 多個中文版本 | AI/IT 系統接受度 |
| UTAUT（統一接受理論） | Venkatesh et al. (2003) | 有台灣驗證版 | 組織層級科技採用 |
| SUS（系統使用性量表） | Brooke (1996) | 有中文版 | 系統易用性評估 |

### 4.2 護理研究常用

| 量表 | 說明 | 備註 |
|-----|------|------|
| 護理能力量表（NCS） | 護理核心能力 | 需確認台灣版本信效度 |
| 臨床推理自評量表 | 臨床判斷能力 | Lasater (2007) LCJR |
| 工作滿意度量表 | 護理工作滿意 | Minnesota Satisfaction Questionnaire |
| 專業承諾量表 | 護理專業認同 | 需翻譯授權 |

⚠️ **量表使用注意事項**：
- 使用他人發展的量表**必須取得原作者授權**（Email 聯繫）
- 中文化流程：原文 → 中文翻譯 → 英文回譯 → 專家審查 → 預試
- 需在論文中說明翻譯流程與信效度驗證結果

## 五、台灣學術寫作慣例

### 5.1 碩士論文章節格式

```
台灣碩士論文標準章節（依各校略有差異）：
第一章 緒論
  1.1 研究背景與動機
  1.2 研究目的
  1.3 研究問題（或研究假設）
  1.4 名詞釋義
  1.5 研究範圍與限制
第二章 文獻探討
  2.1 [核心概念一]
  2.2 [核心概念二]
  2.3 相關研究
第三章 研究方法
  3.1 研究設計
  3.2 研究對象與抽樣
  3.3 研究工具
  3.4 資料收集程序
  3.5 資料分析
  3.6 研究倫理
第四章 研究結果
第五章 討論
第六章 結論與建議
  6.1 結論
  6.2 研究限制
  6.3 未來研究建議
  6.4 實務建議
參考文獻
附錄（問卷、訪談大綱、IRB 核准函、知情同意書）
```

### 5.2 引用格式提醒

```
台灣碩論常見格式：
  → 多數採 APA 7th
  → 部分護理所採 APA 6th（確認指導教授要求）
  → 中文文獻排列：依作者姓氏筆畫排序
  → 英文文獻排列：依作者姓氏字母排序
  → 中英文分開列出：中文在前，英文在後
```
