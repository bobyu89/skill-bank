# 影像特徵與診斷對照速查

## X-Ray 胸部

| 影像描述 | 鑑別診斷 |
|----------|----------|
| Air-space consolidation，單葉 | 細菌性肺炎（Lobar pneumonia）|
| 雙側瀰漫浸潤，蝴蝶翼狀 | 肺水腫（Pulmonary edema）|
| Kerley B lines + 心臟擴大 | CHF |
| 氣管偏移向患側 + 肺體積縮小 | 肺塌陷（Atelectasis）|
| 氣管偏移向健側 + 患側透亮增加 | 張力性氣胸（Tension pneumothorax）|
| 肋膜角消失，D 形陰影 | 肋膜積液（Pleural effusion）|
| Eggshell calcification 肺門淋巴結 | Silicosis |
| Upper lobe fibrosis + cavity | 結核病（TB）|
| 肺部多發結節（cannon ball） | 轉移性肺癌 |
| Bat wing / Butterfly appearance | 肺水腫 |
| Honeycomb pattern | 肺纖維化（IPF）|
| Hilar adenopathy + bilateral infiltrates | Sarcoidosis |

## CT 腹部

| 影像描述 | 診斷 |
|----------|------|
| 胰臟周圍液體積聚 + 胰臟腫大 | 急性胰臟炎 |
| 腸系膜脂肪條紋狀（fat stranding）+ 闌尾擴大 | 急性闌尾炎 |
| 腸壁氣體（pneumatosis intestinalis）| 腸缺血（壞死）|
| 膽管擴張 + 膽總管結石 | 膽道梗阻 |
| 肝臟多發低密度病灶（蜂窩狀）| 肝膿瘍（Amebic/Pyogenic）|
| 主動脈周圍血腫 | 主動脈剝離或破裂 |

## MRI 腦部

| 影像描述 | 診斷 |
|----------|------|
| DWI 高訊號（急性期）| 急性缺血性腦中風 |
| T2 高訊號，white matter | MS plaque |
| Ring-enhancing lesion | 腦膿瘍 / 腦轉移 / GBM |
| Hemorrhage T1 高訊號 | 腦出血（亞急性期）|
| Bilateral basal ganglia T2 高訊號 | Wilson disease / CO 中毒 |

## 心電圖重點（ECG）

| 特徵 | 診斷 |
|------|------|
| ST elevation + reciprocal change | STEMI |
| ST depression + T wave inversion | NSTEMI / UA |
| Delta wave + short PR | WPW syndrome |
| Prolonged QT | 藥物（Amiodarone, Sotalol, TCA）/ 電解質異常 |
| Peaked T waves | Hyperkalemia（早期）|
| Flattened T + U wave | Hypokalemia |
| Epsilon wave（右束支形態後）| ARVC |
| Saddle-back ST elevation | Brugada syndrome |
| PR depression + diffuse ST elevation | Pericarditis |
