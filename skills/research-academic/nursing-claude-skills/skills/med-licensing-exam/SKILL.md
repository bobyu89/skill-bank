# 醫師國考解題 Skill

## Overview

本 skill 將使用者輸入的醫學題目，透過嚴密的 Chain-of-Thought 推理流程解析，整合基礎醫學機制與臨床診斷邏輯，協助考生建立結構化知識體系。

---

## Step 0：輸入辨識與分類

在開始解題前，先判斷輸入類型，選擇對應路徑：

| 輸入類型 | 處理路徑 |
|----------|----------|
| 完整題目（題幹 + 選項）| → 執行完整 5-Step CoT 解題流程 |
| 只有題幹，無選項 | → 先列出鑑別診斷 + 推薦次要檢查，再說明推理 |
| 考點/機轉複習請求 | → 直接輸出「高頻考點整理」格式 |
| 圖片/影像描述題 | → 先轉化影像特徵為診斷線索，再套用 CoT |
| 要求給口訣/記憶法 | → 輸出「大師筆記」格式，含口訣與臨床陷阱 |

> ⚠️ **負向題型警示**：若題幹含有「何者**不**正確」、「何者為**非**」、「最**不**適當」、「**除了**哪項」等字眼，在 Section 1 開頭用粗體 + ⚠️ 標示，避免考生慣性選正確選項。

---

## Step 1：啟動解題前的心態設定

- 以「臨床帶教主治醫師」的角度解釋，而非只給答案
- 每道題都要找出「命題者想考的核心知識點」
- 優先連結基礎醫學機制（一階）到臨床表現（二階）

---

## 完整解題流程（5-Step Chain of Thought）

### 【Section 1】病例特徵摘要

從題幹中系統性提取：

```
患者基本資料：年齡、性別、職業（若有）
主訴（Chief Complaint）：
時間軸：急性 / 亞急性 / 慢性
陽性發現（Pertinent Positives）：
陰性發現（Pertinent Negatives）：關鍵的「沒有」同樣重要
關鍵檢查數值：實驗室、影像、生命徵象異常值
⚠️ 題型警示：[若為負向提問則在此標示]
```

**核心診斷線索（Key Clues）**：用 3 條以內最關鍵的線索直指答案方向。

---

### 【Section 2】思維鏈推演：機制與邏輯

採用以下結構化推導：

**Step 2a：基礎醫學定位**
- 受損解剖構造 / 代謝路徑 / 致病機轉是什麼？
- 正常生理 → 疾病狀態下的病理生理改變

**Step 2b：症狀-機制對應**
- 每個主要症狀/檢查異常 → 對應的病理機轉
- 格式：「[症狀] ← [機轉] ← [根本病因]」

**Step 2c：臨床診斷推導**
- 最可能診斷是什麼，為什麼？
- 若為治療題：目前處置的優先順序依據是什麼（緊急度/可逆性/後果）？

---

### 【Section 3】選項分析與排除

逐一分析每個選項，格式如下：

```
(A) [選項內容]
→ 分析：[此選項的醫學概念是否正確]
→ 與本題的關係：[符合/不符合題幹，為什麼]
→ 結論：✅ 正確答案 / ❌ 排除（排除原因）/ ⚠️ 誘答陷阱（說明迷惑點）
```

**誘答陷阱（Distractor）分析**：
- 指出哪個選項最容易讓人誤選
- 說明命題者設置此陷阱的邏輯

---

### 【Section 4】高頻考點連結

連結到國考常考知識點，格式：

**本題核心考點**：[單一最重要知識點]

**延伸考點**（可能的變形考法）：
- 變形 1：若改成「[不同情境]」→ 答案變為？
- 變形 2：若問「下一步處置」→ 應選？
- 變形 3：若問「最可能的病理機轉」→ 應選？

**相關分類/Staging/Criteria**（若適用）：
- 提供該疾病的分類標準、診斷準則（如 NYHA、Child-Pugh、TNM、DSM-5 等）

**常考數字/公式**（若適用）：
```
[公式名稱]: [公式] 
本題代入: [代入計算]
```

---

### 【Section 5】大師考前筆記

**🧠 記憶口訣**：
> [朗朗上口、有助記憶的口訣]

**🔗 一階-二階整合記憶**：
> [基礎醫學機制 → 臨床表現 → 治療選擇，串成一條記憶鏈]

**⚠️ 臨床陷阱（考試常見錯誤）**：
- 陷阱 1：[常見誤解]
- 陷阱 2：[類似疾病的鑑別點]

**📌 國考 vs 臨床實務差異**（若有衝突需標示）：
> 若國考標準答案與最新臨床指引有出入，此處主動說明差異，避免考生在考場上用「最新實證」覆蓋「國考標準」。

## 特殊題型處理指引

### 影像/病理切片題
當題幹描述 X-ray、CT、MRI、病理切片特徵時：
1. 將文字描述還原為「看到的影像」
2. 列出該影像特徵的鑑別診斷
3. 用其他臨床線索縮小範圍

常見影像描述-診斷對照表 → 見 `references/imaging-clues.md`

### 藥理題
處理順序：
1. 藥物機轉（作用點、受體型別）
2. 預期藥效 vs 副作用
3. 禁忌症（特別注意腎功能、肝功能、懷孕分級）
4. 藥物交互作用

常見藥物考點 → 見 `references/pharmacology-high-yield.md`

### 統計/流行病學題
1. 識別題目要求計算的指標（Sensitivity, Specificity, PPV, NPV, OR, RR, NNT 等）
2. 建立 2×2 Table（若為診斷題）
3. 代入公式計算
4. 解釋臨床意義

公式速查 → 見 `references/biostatistics-formulas.md`

## 輸出格式規範

- **語言**：使用繁體中文；英文醫學術語保留（如 atrial fibrillation、RAAS），首次出現加中文說明
- **長度**：完整解題約 600–1000 字；複習/考點整理依需求調整
- **結構**：嚴格遵守 Section 1–5，不可省略（除非題型不需要 Section 5）
- **Disclaimer**：每次回覆末尾附上：

## 知識領域覆蓋範圍

**基礎醫學（一階重點）**
- 解剖學（含放射解剖）、組織學、胚胎學
- 生理學（心肺腎、神經、內分泌）
- 生物化學（代謝路徑、酵素異常）
- 微生物學與免疫學（病原體機轉、疫苗、免疫缺損）
- 藥理學（機轉、副作用、禁忌、交互作用）
- 病理學（細胞損傷、腫瘤、系統病理）

**臨床醫學（二階重點）**
- 內科：心臟、胸腔、腎臟、消化、血液腫瘤、感染、內分泌、神經
- 外科：急腹症、外傷、腫瘤外科
- 婦產科：產科急症、婦科腫瘤、不孕症
- 兒科：新生兒、發育、兒童感染、先天性疾病
- 精神科：DSM-5 診斷標準、藥物治療
- 醫學倫理與法律：知情同意、強制住院、醫療糾紛
