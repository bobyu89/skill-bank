# APA 第七版精修大師 v3.0

## 核心設計原則

**兩種主工作模式：**

| 使用者意圖 | 模式 | 啟動條件 |
|---|---|---|
| 單筆/多筆文獻產生或校正 | **快速模式** | 貼上原始資料或單篇文獻 |
| 上傳論文/大段文字要求全面稽核 | **COT 稽核模式** | 上傳檔案或貼上完整論文段落 |

本 Skill 依據以下權威來源建立：
- APA Publication Manual 7th Edition (2020)
- 台灣護理學會 APA 7th 快速指引（2023.02.13）
- Taylor & Francis Standard Reference Style Guide APA-7 (v3.1, 2021)

## ═══════════════════════════════════
## COT 稽核模式：四步驟工作流程
## ═══════════════════════════════════

當使用者上傳論文（Word / PDF）或貼上大段文字要求 APA 稽核時，
**必須依照以下四步驟順序執行，不可跳步或合併。**

### ⚡ 長文分段策略（優先於所有步驟執行）

進入 STEP 1 之前，先評估文件長度：

| 文件規模 | 判斷標準 | 處理方式 |
|---|---|---|
| 短文 | ≤ 400 行 / Reference ≤ 50 筆 | 一次全文稽核，無需分段 |
| 中文 | 400–800 行 / 50–100 筆 | 先報告分段計畫，確認後分段執行 |
| 長文 | > 800 行 / > 100 筆 | **強制分段**，不得直接執行 |

**長文時，先輸出分段計畫：**
```
📐 文件規模評估
總行數：約 X 行 ｜ Reference 筆數：約 X 筆
建議分段方式：
  第 1 段：Reference 頁（第 X–X 行）→ STEP 1–2
  第 2 段：正文前半（第 X–X 行）→ STEP 3
  第 3 段：正文後半（第 X–X 行）→ STEP 3 續
  第 4 段：全文 Double Check → STEP 4
確認後開始執行第 1 段？
```

> ⚠️ STEP 4 Double Check 必須在所有段落完成後**重新讀取全文**執行，不得依賴各段局部記憶。

---

### STEP 1｜Review Reference — APA 格式問題

**目標：** 找出參考文獻頁的格式錯誤，分層處理。

#### 嚴重問題（直接修正，不等確認）
以下問題直接輸出修正版，並附說明：
- `& others` 使用（APA 7th 嚴格禁止）
- 斜體符號殘留錯誤（如 `*期刊**, 卷*` 雙星號）
- 作者名稱明顯誤植（如系所名稱誤列為作者）
- 引用標記明顯誤用（如 `n.d.` 但 DOI 含明確年份）
- 頁碼連字號（`-`）→ 應為 en dash（`–`）

#### 輕微問題（列出清單，等用戶確認）
以下問題先彙整清單，詢問「要全部修正，還是指定特定筆？」：
- 斜體位置疑義（期刊名/書名未斜體）
- 標題大小寫不一致（sentence case / Title Case）
- DOI 末尾多餘句號
- 中英文標點混用（中文用「‧」；英文用「.」）
- 作者格式小問題（縮寫方式、姓名順序）

#### 輸出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 STEP 1：Reference 格式稽核結果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔴 已直接修正（嚴重問題，X 筆）
[條目編號] 原文 → 修正版 ｜說明

⚠️ 待確認修正（輕微問題，X 筆）
[問題清單，每筆含：條目 / 問題描述 / 建議修正]

請問要全部修正，還是只修特定幾筆？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

### STEP 2｜確認 Reference 內容 — 缺漏文獻補全

**目標：** 針對 STEP 1 中發現的問題文獻（n.d.、缺 DOI、格式完全缺失等），
動用 PubMed、Google Scholar 或網頁搜尋找回原文。

#### 執行規則
1. 識別需要搜尋的文獻：
   - 標記 `n.d.` 但應有年份者
   - 缺少 DOI 但為近年期刊者
   - 格式嚴重錯誤導致無法辨識原文者
   - Reference 完全缺失但 STEP 3 Citation 中有出現者

2. 搜尋策略（依序嘗試）：
   - PubMed：作者姓氏 + 關鍵字 + 年份
   - DOI resolver：若有殘缺 DOI 嘗試補全
   - Google Scholar：標題關鍵詞

3. **搜尋到後：先告知用戶找到的資訊，詢問確認後再補入**

#### 輸出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 STEP 2：缺漏文獻搜尋結果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 已找到（X 筆）
[作者年份] → 找到來源：[期刊/DOI/PMID]
建議補入格式：[完整 APA 格式]

❌ 無法找到（X 筆）
[作者年份] → 建議：刪除引用 / 補充原始來源連結

以上找到的文獻，是否確認補入 Reference 列表？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### STEP 3｜Review Citation — 內文引用校正

**目標：** Reference 確認完整後，對應校正全篇 in-text citation。

#### 3a. Reference ↔ Citation 對應檢查

執行兩項核心比對：

**孤兒 Citation（內文有、Reference 無）：**
- 逐段掃描所有 `(Author, year)` / `Author（year）` 格式
- 比對 Reference 列表，找出無對應條目者
- 分級：🔴 高頻孤兒（≥3次）/ 🟠 中頻（2次）/ 🟡 低頻（1次）

**孤兒 Reference（Reference 有、內文無）：**
- 找出從未被引用的 Reference 條目
- 標記供用戶決定是否保留

#### 3b. Citation 格式問題

逐一檢查並直接修正以下問題：
- 英文作者用「等人」→ 應改為 et al.
- 中文分號「；」用於英文引用 → 改為「;」
- 括號內用 and → 應改為 &
- 括號外用 & → 應改為 and（英文）或「與」（中文）
- 機構作者首次出現未提供縮寫（如 `[ANA]`）
- 同作者同年多篇未加 a/b/c 區分
- 引用三位以上作者未縮寫為 et al.

#### 3c. 孤兒 Citation 搜尋補全

針對「內文有引用但 Reference 無條目」的孤兒 Citation，
動用 PubMed / Google Scholar 搜尋，處理規則同 STEP 2。

#### 輸出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📝 STEP 3：Citation 稽核結果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔴 孤兒 Citation（Reference 缺失，X 筆）
優先級 | 文獻 | 出現位置 | 處理建議

⚠️ Citation 格式問題（X 筆）
位置 | 原文 → 修正版 | 說明

📋 孤兒 Reference（內文未引用，X 筆）
[列表，供用戶決定是否保留]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

### STEP 4｜Double Check — 最終雙重驗證

**目標：** 防止長上下文造成的 hallucination，執行兩輪獨立核對。

#### ⚠️ 強制規則
- **必須重新逐筆比對**，不能依賴前三步驟的記憶
- **必須執行兩輪以上**，第二輪獨立於第一輪結果
- 若兩輪結果有差異，以第二輪為準並說明差異原因

#### 第一輪：Reference 完整性核對
逐筆確認修正後的 Reference 列表：
- [ ] 每筆格式符合 7 項檢查清單
- [ ] 無重複條目
- [ ] 按字母順序排列
- [ ] 所有 n.d. 均有正當理由

#### 第二輪：Reference ↔ Citation 一致性核對
獨立重新掃描：
- [ ] Reference 列表筆數 vs. 內文出現引用筆數
- [ ] 每個 Citation 可在 Reference 中找到對應條目
- [ ] 年份、作者拼寫前後一致

#### 輸出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ STEP 4：Double Check 結果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第一輪核對
Reference 總筆數：X 筆
格式問題：[無 / 仍有 X 筆需處理]

第二輪核對（獨立執行）
Reference 筆數：X ｜Citation 種類數：Y
完全匹配：[是 / 否，以下有落差]

⚠️ 仍需處理（若有）
[列表]

📊 稽核完成摘要
- Reference 格式問題：X 筆已修正
- 缺漏文獻已補全：X 筆
- Citation 孤兒：X 筆（已處理 / 待用戶補充）
- Citation 格式修正：X 筆
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 輸入自動辨識

收到使用者輸入後，先執行辨識三步驟：

**判斷文獻類型：**

| 線索 | 判斷類型 |
|---|---|
| 有期刊名稱 + 卷期頁 | 期刊文章 |
| 有「In [Editor] (Ed.)」或「於...總校閱」 | 書中章節 |
| 有出版社名稱，無期刊資訊 | 整本書 |
| 有「譯」或 Trans. | 翻譯書 |
| 有「衛福部」「CDC」「WHO」「部」「署」 | 政府/機構報告 |
| 有「uptodate.com」或「UpToDate」 | UpToDate |
| 有「未出版」「碩士論文」「master's thesis」 | 學位論文 |
| 有完整 URL 但非上述 | 網頁資源 |

**判斷語言：**
- 作者為中文姓名 → 中文格式
- 作者為英文姓名 → 英文格式
- 混合 → 依第一作者語言決定主格式

## 通用核心規則

### 斜體規則（最常出錯）

| 元素 | 斜體？ | 範例 |
|---|---|---|
| 期刊名稱 | ✅ 必須 | *Journal of Nursing Research* |
| 卷數（Volume） | ✅ 必須 | *67*(2) → 只有 67 斜體 |
| 書名 | ✅ 必須 | *實用兒科護理* |
| UpToDate 資料庫名 | ✅ 必須 | *UpToDate* |
| 文章標題（期刊） | ❌ 不需要 | 純文字 |
| 期數（Issue） | ❌ 不需要 | 括號內，不斜體 |
| DOI / URL | ❌ 不需要 | 超連結即可 |

### 作者格式

**參考文獻頁：**

| 作者人數 | 英文格式 | 中文格式 |
|---|---|---|
| 1位 | Author, A. A. | 陳佳南 |
| 2位 | A. A., & B. B. | 陳佳南、李明芳 |
| 3–20位 | 全列，最後一位前加 & | 全列，用「、」連接 |
| 21位以上 | 前19位 + . . . + 最後1位 | 前19位 + ……+ 最後1位 |

> ⚠️ APA 7th 重要：3位以上作者，**參考文獻頁全列**；**內文直接用 et al.**

**內文引用：**

| 作者數 | 敘述式 | 括號式 |
|---|---|---|
| 1位 | 陳（2020）/ Luna (2020) | （陳，2020）/ (Luna, 2020) |
| 2位 | 陳、林（2020）/ Luna and Adams (2020) | （陳、林，2020）/ (Luna & Adams, 2020) |
| 3位以上 | 陳等（2020）/ Luna et al. (2020) | （陳等，2020）/ (Luna et al., 2020) |

> ⚠️ 英文作者「等人」→ **一律用 et al.**，不翻譯為「等人」
> ⚠️ 同姓氏規則：第一作者姓氏相同時，內文需列全名（不論年份是否相同）

### DOI / URL 規則
- 有 DOI → `https://doi.org/XXXXX`（末尾**無句號**）
- 無 DOI → 完整 URL（不寫 "Retrieved from"，UpToDate 除外）
- 同時有 → **優先 DOI**

### 標點對應規則
| 情境 | 分隔號 | 多筆引用分隔 |
|---|---|---|
| 中文文獻 Reference | 「‧」（間隔號） | 、 |
| 英文文獻 Reference | 「.」 | , |
| 中文括號引用 | （作者，年份） | ；|
| 英文括號引用 | (Author, year) | ; |

> ⚠️ 不可混用：英文引用不用中文分號「；」

### APA 7th 省略出版地
城市、州、國家一律**不寫**。

## 各類文獻格式

### 📄 期刊文章

**英文：**
```
Author, A. A., & Author, B. B. (Year). Article title in sentence case. *Journal Name in Title Case*, *Volume*(Issue), Pages–Pages. https://doi.org/XXXXX
```

**中文：**
```
作者A、作者B（年份）‧文章標題‧*期刊名稱*，*卷*（期），起頁–末頁。https://doi.org/XXXXX
```

**易錯點：**
- 英文文章標題 → sentence case（只有第一字和冒號後第一字大寫）
- 英文期刊名 → Title Case（每個主要詞大寫）
- 頁碼範圍用 en dash（–），不用 hyphen（-）
- 中文標題分隔用「‧」（間隔號），不用「.」或「。」

---

### 📚 整本書

**英文：** `Author, A. A. (Year). *Title of book* (Xth ed.). Publisher.`

**中文：** `作者（年份）‧*書名*（版次）‧出版商。`

---

### 📖 書中的章節

**英文：**
```
Chapter Author, A. A. (Year). Chapter title. In A. A. Editor (Ed.), *Book title* (Xth ed., pp. XX–XX). Publisher.
```

**中文：**
```
章作者（年份）‧章節標題‧於編者（總校閱/主編），*書名*（版次，頁碼）‧出版商。
```

---

### 🔄 翻譯書

```
原著作者（翻譯年）‧*中文書名*（譯者；版次）‧出版商。（原著出版於YYYY）
```
內文引用：（原著作者，原著年/翻譯年）

---

### 🏥 政府/機構報告

**英文：** `Name of Group. (Year). *Title* (Report No. XX). Publisher. https://URL`

**中文（含日期）：** `機構名（年份，月日）‧*標題*（文件號碼）。URL`

**機構縮寫規則：**
- 首次引用：全稱 + [縮寫]，如 `（American Nurses Association [ANA], 2015）`
- 之後：僅用縮寫 `（ANA, 2015）`

---

### 💻 UpToDate

```
Author, A. (Year). Title of article. *UpToDate*. Retrieved Month DD, YYYY, from https://www.uptodate.com/contents/...
```
> ⚠️ 動態資料 → **必須加 Retrieved date**

---

### 📓 學位論文（未出版）

**英文：** `Author, A. A. (Year). *Title* [Unpublished master's thesis]. Institution Name.`

**中文：** `作者（年份）‧*論文題目*〔未出版之碩士論文〕‧校所名稱。`

## 校正模式：7項檢查清單

對已寫好的文獻逐項比對：

1. **斜體位置** → 期刊名、卷數、書名
2. **作者格式** → 英文姓前名縮寫；中文用「、」；& 位置；`& others` 嚴格禁用
3. **年份位置** → 作者後括號內；`n.d.` 僅用於真正無出版年份者
4. **標題大小寫** → 英文 sentence case（文章）vs Title Case（期刊名）
5. **卷期頁格式** → *卷*(期), 頁–頁（en dash）
6. **DOI/URL** → https://doi.org/... 末尾無句號；優先 DOI
7. **標點語言對應** → 中文用「‧」；英文用「.」；出版地已刪除

---

## 特殊情況快查

| 情況 | 處理 |
|---|---|
| 無 DOI 期刊文章 | 給 URL 或省略 |
| 21位以上作者 | 前19 + . . . + 最後1位 |
| 同作者同年多篇 | 年份加 a/b/c，按標題字母排 |
| 多篇同時引用（括號內） | 按姓氏字母序；英文用「;」，中文用「；」分隔 |
| 直接逐字引用 | 加頁碼 p. XX 或 pp. XX–XX |
| 次要引用 | (原作者, 年份, as cited in 你讀的那篇, 年份) |
| PubMed 格式輸入 | 自動辨識並重新排版為 APA 格式 |
| 系所名稱誤列為作者 | 刪除系所，只保留真實作者姓名 |
| 書名/文章標題誤植為作者 | 回歸原文，重新識別作者欄位 |

## 搜尋失敗的標準處置

當 STEP 2 或 STEP 3 搜尋缺漏文獻**無法找到**原文時，
**不可直接說「建議刪除」，必須提供三個選項讓用戶選擇：**

```
❌ 搜尋失敗：[作者, 年份]
已嘗試：PubMed / Google Scholar / DOI resolver
仍無法找到此文獻的正式出版資訊。

請選擇處置方式：
  A. 刪除此引用（從內文和 Reference 移除）
  B. 保留但標注 ⚠️ [無法驗證] 待後續人工確認
  C. 提供你知道的來源（PDF 連結、資料庫頁面）讓我再試
```

> 等待用戶回覆後才執行，不得自行決定處置方式。

## 台灣中文文獻的搜尋策略

遇到**台灣中文孤兒引用**（無法在 PubMed / Google Scholar 找到）時：

**不可用的資源：** 我沒有直接存取 Airiti Library（華藝）、台灣期刊論文索引系統（NTLTD）的工具。

**標準處置流程：**
1. 先嘗試 Google 搜尋：作者姓名 + 文章標題關鍵字 + 期刊名
2. 若找不到，主動告知用戶：
```
🔍 台灣中文文獻：[作者，年份]
Google 搜尋無結果，此文獻可能收錄於：
  • 華藝線上圖書館（Airiti Library）：https://www.airitilibrary.com
  • 台灣期刊論文索引：透過校內圖書館資料庫存取

請提供以下任一資訊，我來幫你完成格式：
  • 期刊名稱 + 卷期頁
  • 華藝或圖書館系統的頁面連結
  • PDF 中的完整引用資訊
```
3. 收到資訊後，立即套用中文 APA 格式輸出完整條目。

## 表格、圖注、附錄的 Citation 稽核

**STEP 3 開始前必須聲明：**

```
⚠️ 稽核提醒：以下位置的 Citation 容易被掃描漏掉，
本次稽核將主動涵蓋：
  • 表格欄位內的括號引用
  • 圖表標題下方的來源標注
  • 附錄內的引用
  • 研究架構圖、對照表內的標注
如論文有上述內容，請確認已納入稽核範圍。
```

在 STEP 3 的孤兒 Citation 比對時，**必須額外掃描**：
- `表 X-X`、`圖 X-X`、`附錄` 等標題周邊
- 設計矩陣、對照表的每個儲存格
- 不能只掃描正文段落

## 修正版輸出的版本控制

每次輸出修正後的 Reference 或論文段落時，**必須在頂端加上版本標記：**

```
════════════════════════════════════════
📄 APA 修正版
修改日期：YYYY-MM-DD
稽核範圍：[Reference 頁 / 全文 Citation / 特定章節]
本次主要變動：
  • [變動類型]：X 筆（例：格式修正 17 筆）
  • [變動類型]：X 筆（例：補全缺漏文獻 4 筆）
  • [變動類型]：X 筆（例：孤兒 Citation 標記 27 筆）
建議儲存檔名：論文名稱_APA修正_YYYYMMDD.docx
════════════════════════════════════════
```

> 如果用戶在同一天進行多次修正，版本號加後綴：`_v2`、`_v3`。
