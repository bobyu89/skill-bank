## 標題與摘要 {#標題與摘要}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 1.1 | 標題精確反映研究內容，不誇大不模糊 | [ ] |
| 1.2 | 標題含關鍵字，利於搜尋（避免縮寫除非極常見） | [ ] |
| 1.3 | 標題標示研究設計類型（RCT / systematic review / cohort 等） | [ ] |
| 1.4 | 摘要包含完整 IMRAD 結構（背景/目的/方法/結果/結論） | [ ] |
| 1.5 | 摘要中有具體數據（樣本數、主要效果量、p 值或 CI） | [ ] |
| 1.6 | 摘要字數符合目標期刊要求 | [ ] |
| 1.7 | 結構式摘要 vs 非結構式符合期刊規定 | [ ] |
| 1.8 | 關鍵字 3-5 個，涵蓋主題、方法、族群，含 MeSH terms | [ ] |

## 研究方法 {#研究方法}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 2.1 | 研究設計明確標示（RCT / quasi-experimental / cross-sectional 等） | [ ] |
| 2.2 | 納入排除標準清楚列出 | [ ] |
| 2.3 | 樣本量有 power analysis 或正當理由說明 | [ ] |
| 2.4 | 變項操作型定義明確 | [ ] |
| 2.5 | 資料蒐集工具/量表有信效度報告 | [ ] |
| 2.6 | 統計方法適合研究設計和資料類型 | [ ] |
| 2.7 | 缺失值處理方式已說明 | [ ] |
| 2.8 | 若為 RCT：隨機化方法、分配隱藏、盲法已描述 | [ ] |
| 2.9 | 若為質性：理論框架、抽樣策略、資料飽和已說明 | [ ] |
| 2.10 | 遵循對應報告規範（CONSORT/STROBE/PRISMA/STARD 等） | [ ] |

## 結果呈現 {#結果呈現}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 3.1 | 所有預定分析的結果均有報告（無 selective reporting） | [ ] |
| 3.2 | 效果量（effect size）已報告 | [ ] |
| 3.3 | 信賴區間（95% CI）已報告 | [ ] |
| 3.4 | 若有多重比較，已說明校正方法 | [ ] |
| 3.5 | 結果文字與表格數據一致（無矛盾） | [ ] |
| 3.6 | 負面結果/非顯著結果也已報告 | [ ] |

## 討論與結論 {#討論與結論}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 4.1 | 結論有數據直接支持，無過度推論 | [ ] |
| 4.2 | 與既有文獻充分比較（不只引用支持自己的文獻） | [ ] |
| 4.3 | 研究限制誠實且具體列出 | [ ] |
| 4.4 | 未來研究方向具體可行 | [ ] |
| 4.5 | 臨床/實務意涵清楚闡述 | [ ] |
| 4.6 | 跨節一致性：Discussion 無新增 Results 未呈現的主張 | [ ] |

## 參考文獻 {#參考文獻}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 5.1 | 引用格式統一（APA 7th / Vancouver / 期刊指定） | [ ] |
| 5.2 | 文內引用與文末列表一一對應 | [ ] |
| 5.3 | 包含近 5 年的最新文獻 | [ ] |
| 5.4 | 關鍵文獻未遺漏（特別是該領域重要 review 和相反發現） | [ ] |
| 5.5 | DOI 已包含（若期刊要求） | [ ] |
| 5.6 | 自引比例合理（通常 <15-20%） | [ ] |

## 圖表 {#圖表}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 6.1 | 每張圖表都有獨立標題和說明，可自明 | [ ] |
| 6.2 | 圖表中所有縮寫在說明中定義 | [ ] |
| 6.3 | 單位標示清楚（坐標軸、欄位標頭） | [ ] |
| 6.4 | 圖片解析度符合期刊要求（通常 ≥300 dpi） | [ ] |
| 6.5 | 表格無多餘線條（三線表或期刊指定格式） | [ ] |
| 6.6 | 圖表編號與文中引用順序一致 | [ ] |
| 6.7 | 若有 CONSORT / PRISMA flow diagram，已包含 | [ ] |

## 格式與合規 {#格式與合規}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 7.1 | 總字數符合期刊限制 | [ ] |
| 7.2 | 各節字數比例合理（Methods 和 Results 佔主體） | [ ] |
| 7.3 | 字型、行距、邊距符合投稿須知 | [ ] |
| 7.4 | 頁碼和行號已加入（若要求） | [ ] |
| 7.5 | 標題層級格式統一 | [ ] |
| 7.6 | 縮寫首次使用時已定義 | [ ] |
| 7.7 | 英文語法和用詞專業（或已請母語者校稿） | [ ] |
| 7.8 | 無抄襲問題（已通過 Turnitin / iThenticate） | [ ] |

## 投稿技術要求 {#投稿技術要求}

| # | 檢查項目 | 通過 |
|---|---------|------|
| 9.1 | Cover letter 已撰寫（含論文亮點和期刊適合性） | [ ] |
| 9.2 | 所有共同作者已確認最終版本 | [ ] |
| 9.3 | 建議審稿人名單已準備（含 email，若期刊要求） | [ ] |
| 9.4 | 排除審稿人名單（若有利益衝突者） | [ ] |
| 9.5 | 補充材料（Supplementary Materials）已整理 | [ ] |
| 9.6 | 檔案格式符合投稿系統要求（.doc/.docx, 圖片另存等） | [ ] |
| 9.7 | 盲審版本已移除所有作者辨識資訊（若為 double-blind） | [ ] |
