# P1：相機校正

目標：取得各相機的內參（焦距、主點、畸變）與外參（相對位置與姿態），
使 2D 影像點能對應到共同的 3D 世界座標。

---

## 為什麼用 ChArUco 而非棋盤格

ChArUco = 棋盤格 + ArUco 標記。優點：

- **部分遮擋時仍可用**——純棋盤格必須完整可見，多相機校正時很難讓每台都看到全板。
- **自動判斷方向**——不會發生棋盤格 180° 翻轉導致對應錯誤。
- **角點精度與棋盤格相同**——不犧牲精度。

需要 `opencv-contrib-python`（`aruco` 模組不在基礎版）。

---

## 流程

### 1. 內參校正（每台相機各自進行）

拍攝 ChArUco 板在不同位置、角度、距離的影像 20–40 張。要點：

- 涵蓋畫面**各個區域**，尤其是邊角——畸變在邊緣最明顯，取樣不足會使畸變係數估計不準。
- 涵蓋不同**傾斜角度**——只拍正對的影像無法解出焦距與距離的耦合。
- 板面應佔畫面相當比例（至少三分之一）。

### 2. 外參校正（相機之間）

讓校正板同時被多台相機看見，求解相對位姿。

實務困難：六台環繞配置時，不可能所有相機同時看到板。做法：
- 建立相機間的**兩兩關係圖**，只要圖是連通的即可推導全域外參。
- 以束調整（bundle adjustment）全域優化，減少誤差累積。

### 3. 品質驗證（兩道，缺一不可）

**第一道：重投影誤差 < 1.0 px**

這是必要條件但**不充分**。

**第二道：已知長度物件的重建誤差 < 1%**

在場景中放一把已知長度的尺（或已知間距的兩個標記），
重建後量測長度，比對真值。

**為什麼需要第二道：** 重投影誤差低但**尺度錯誤**的情況並不罕見——
優化可能收斂到一個內部自洽但整體縮放錯誤的解。
只看重投影誤差會完全漏掉這個問題，而尺度錯誤會使所有力矩計算失準。

## 校正的有效期管理

校正結果在以下情況失效：

- 相機被移動或碰撞
- 相機重新插拔 USB（部分機型會重置對焦）
- 相機設定改變（解析度變更會改變內參）

因此校正檔必須記錄：

```
Calibration
├─ calibration_id
├─ intrinsics, extrinsics
├─ reprojection_error_px
├─ scale_check_error_pct        # 第二道驗證的結果
├─ created_at
├─ camera_settings_hash         # 解析度等設定的雜湊，載入時比對
└─ valid_from, valid_until
```

載入校正檔時應驗證 `camera_settings_hash` 與當前設定相符，
不符則拒絕載入並提示重新校正。

**建議每個資料蒐集日開始前重新校正**，並在當日結束後再驗證一次
（用已知長度物件），確認期間未發生位移。

## 合成資料測試

校正演算法應有往返測試：

```
給定已知相機參數與 3D 板點
  → 投影成 2D（加入已知的畸變）
  → 餵入校正演算法
  → 驗證還原出的參數與原始值的誤差在數值精度內
```

這能立刻抓出座標系慣例、畸變模型、單位（公尺 vs 毫米）的錯誤，
而這些錯誤在真實資料上很難定位。
