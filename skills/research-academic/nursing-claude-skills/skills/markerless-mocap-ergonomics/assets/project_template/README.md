## 安裝

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -e ".[dev]"
pytest                          # 應全數通過
```

姿態估計相關套件（P2 才需要，體積較大）：

```bash
pip install -e ".[pose]"
```

所有測試都不需要相機——硬體邏輯與純運算邏輯刻意分離。

## 快速開始（P0 流程）

### 1. 探索相機

```bash
python scripts/00_discover_cameras.py
```

列出可用相機與支援模式，並**實測多台同時開啟**是否成功。
單台可用不代表多台可用——USB 頻寬不足時通常靜默失敗而非報錯。

確認索引與實體機位的對應：

```bash
python scripts/00_discover_cameras.py --preview 0 1 2 3
```

記下對應關係後填入 `configs/cameras.yaml`。

### 2. 錄製

```bash
python scripts/01_record.py --trial T001 --duration 30
```

**錄製開始後兩秒內必須觸發一次 LED 閃光**，且所有相機都要看得到。
這是事後對齊各相機時間軸的唯一依據，漏做則該次試作無法使用。

### 3. 檢查同步

```bash
python scripts/02_check_sync.py data/raw/<日期>_T001 --roi 800 100 200 200
```

`--roi` 指定 LED 所在區域。不指定會用全畫面平均亮度，
容易被人員移動稀釋而偵測失敗。

輸出 `sync.json`，供後續三維重建使用。

## LED 同步裝置

不需要買現成產品：一顆高亮度白光 LED（5 mm）+ 按鈕開關 + 3V 鈕扣電池，
串聯即可，成本不到一百元。

要點是**放在所有相機都看得到、且不會被人員遮擋**的位置。

手邊沒有零件時，用手機手電筒快速開關一次也可以，
只是亮度變化的邊緣不如 LED 銳利，次幀內插精度會略差。

---

## 為什麼不用硬體觸發

工業相機有觸發腳位可達微秒級同步，但成本是網路攝影機的五倍以上。
本專案以 LED 閃光配合次幀內插，在 60 fps 下可達 2–5 ms 對齊精度——
相較之下，單純找「第一個變亮的幀」只能達到 16.7 ms。
