## 📖 这是什么

一个为学习《麻醉护理学》（刘保江、晁储璋主编，人民卫生出版社，2013）而设计的教学 Skill。融合了**中医学习导师 Skill 的成熟骨架**（水平评估、四步提问法、间隔重复、进度追踪）与**三个开源教学项目的精华**（learn-claude-code 渐进课程、DeepTutor 可审计记忆、OATutor 知识追踪 + 脚手架）。

适用于：
- 🎓 **护理本科生**——期末备考、系统过教材
- 👩‍⚕️ **麻醉专科护士**——规范化培训、职称晋升
- 🏥 **临床带教**——教学参考、考核出题

## ✨ 核心特色

| 设计支柱 | 说明 |
|:---|:---|
| 🔄 **围术期主循环锚点** | 所有知识回归到主循环（术前评估→准备→诱导→维持→苏醒→恢复），每章只叠加一个新能力 |
| 📚 **教材为体，指南为用** | 核心教材作理论根基，13 份围术期指南作临床决策最新依据，二者平等对照 |
| ⚠️ **安全第一** | 高危操作（恶性高热、局麻药中毒、过敏休克、CPR）强制警示 + 硬掌握闸门 |
| 🎯 **L1-L4 分层教学** | 入门 / 进阶 / 实战 / 精通，不同层级不同教学策略 |
| 📊 **BKT 知识追踪** | 每个知识点量化掌握程度（M 值），最低掌握度优先复习 |
| 🪜 **三级脚手架** | 答错时逐步释放提示（提示 → 子题 → 兜底） |
| 🧠 **三层可审计记忆** | L1 原始事件 → L2 提炼事实 → L3 学习者画像，任何结论可回溯 |
| 🔁 **间隔重复** | 1-3-7-14-30-60 课次，基于遗忘曲线 |

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/<你的用户名>/anesthesia-nursing-tutor.git
cd anesthesia-nursing-tutor
```

### 2. 安装 Skill

将 `skill/` 目录下的 5 个文件复制到你的 ZCode/Claude Code skills 目录：

**Windows（ZCode）**：
```bash
# 复制到全局 skills 目录（推荐，所有项目可用）
cp -r skill/* "C:/Users/<你的用户名>/.zcode/skills/麻醉护理学学习导师/"
```

**macOS / Linux（Claude Code）**：
```bash
cp -r skill/* ~/.claude/skills/麻醉护理学学习导师/
```

> ⚠️ **注意**：复制的是 `skill/` 目录下的**文件**，不是 `skill/` 目录本身。目标是 `<skills目录>/麻醉护理学学习导师/` 下直接放着 `SKILL.md`。

### 3. 配置知识库路径

仓库已内置教材和指南，路径为**仓库内相对路径**。你需要做的只是：

**确认 SKILL.md 中两个路径指向本仓库的绝对位置**（因为 Skill 运行时的工作目录可能是任何地方，建议改成你 clone 后的绝对路径）：

打开 `skill/SKILL.md`，找到「RAG 知识库使用规范」章节，将 `./` 替换为你的仓库绝对路径，例如：

```
# 改前（相对路径，工作目录不一定在仓库根）
./knowledge_base/textbook/13578526_《麻醉护理学》.pdf_by_PaddleOCR-VL-1.6.md

# 改后（你的实际绝对路径）
F:/Users/你的用户名/Desktop/anesthesia-nursing-tutor/knowledge_base/textbook/13578526_《麻醉护理学》.pdf_by_PaddleOCR-VL-1.6.md
```

详细配置见 [`docs/知识库配置指南.md`](docs/知识库配置指南.md)。

### 4. 开始学习

在 ZCode / Claude Code 对话中输入：

```
开始麻醉护理学习
```

AI 会：
1. 首次使用——做水平评估（快速 1 分钟 / 系统测试 15-20 分钟，二选一）
2. 判定你的 L1-L4 层级
3. 从第一章开始系统学习（或根据你的基础跳到合适章节）
4. 按「要点展示 → 概念剖析 → 临床情景 → 四步提问 → 要点总结」流程教学
5. 自动保存笔记 + 更新进度到 `notes/麻醉护理学/`

其他触发语：
- `继续麻醉护理学习`——按进度继续
- `开始麻醉护理测试`——单独做水平评估
- `麻醉护理复习`——触发复习课

## 🎯 L1-L4 层级与教学策略

| 层级 | 判断依据 | 教学策略 |
|:---|:---|:---|
| **L1 入门** | 无临床经验，药理/操作陌生 | 选项引导为主，每个术语自动解释 |
| **L2 进阶** | 学过教材理论，能做简单评估 | 开放提问为主，关键术语解释 |
| **L3 实战** | 有临床实习经验，能独立做护理计划 | 讨论式教学，开放性问题 |
| **L4 精通** | 麻醉专科护士，能处理复杂并发症 | 平等讨论，反向提问，多视角对比 |
