# Subskill: evidence-checker（证据核验）

> **职责**：引用任何医学来源前，执行 5 步核验。确保来源 current、适用、不冲突。**安全关键内容核验不通过时禁止输出。**

---

## 触发条件

任何需要引用 knowledge_sources（法规/SOP/指南/教材）来生成医学解释、护理建议、反馈时，加载本文件。

## 执行前读取

- `references/evidence-policy.md`（四层层级 + 注册表结构）
- `references/critical-content.md`（安全关键内容清单）

---

## 5 步来源检查

每次引用来源前，逐项检查：

### 检查 1：是否为当前版本？

```text
查注册表的 status 字段：
  current    → ✅ 可引用
  superseded → ⚠️ 必须显式说明"此为旧版，已有更新"
                并提示新版本 source_id
  archived   → ❌ 禁止引用
```

### 检查 2：是否适用人群？

```text
查 applicable_population：
  adult      → 仅适用于成人
  pediatric  → 仅适用于小儿
  obstetric  → 仅适用于产妇
  all        → 通用

当前病例患者若为小儿，而来源仅 adult → ❌ 不匹配，另找来源
```

### 检查 3：是否适用于护理决策？

```text
查 applicable_role：
  physician            → 仅医师适用
  nurse                → 护理专用
  anesthesia_provider  → 麻醉相关人员（含护士）
  all                  → 通用

若来源是纯医师指南（如外科医师操作指南）用于护理决策 →
  需注明"此为医师指南，护理执行需遵医嘱和本机构护理 SOP"
```

### 检查 4：是否存在本机构 SOP？

```text
查 institutional_sop 类来源：
  若存在本机构 SOP → 本地流程以 SOP 为准
  指南与 SOP 冲突时 → 展示两者差异，本地按 SOP
```

### 检查 5：是否与其他来源冲突？

```text
对比同主题的其他来源：
  若一致 → 强化标准，多来源互证
  若冲突 → 必须明确展示差异
           按优先级（法规/SOP > 指南 > 教材 > 实践差异）处理
           不得自动混合、不得隐瞒冲突
```

---

## 安全关键内容的严格核验

涉及 critical-content.md 清单（CPR/LAST/MH/过敏/除颤/输血/血管活性药/抢救剂量/全脊麻/阿片呼吸抑制/小儿用药）时：

```text
执行 5 步检查
  ↓ 全部通过
✅ 可引用，必须标注来源+版本+核验信息

  ↓ 任一不通过 / 检索不到
❌ 禁止凭模型记忆输出
   明确说明："当前知识库无法核验此内容"
   提示："请参照本机构现行 SOP 或最新指南"
   提示管理员补充知识来源
   只提供"需要核查的要点清单"，不提供具体数值
```

---

## 输出格式

引用来源时必须标注：

```text
📋 来源：《[名称]》[章节/页码]
📅 版本：[年份]，[current/superseded]
👥 适用：[人群]，[角色]
✅ 核验：[核验人]，[日期]
```

多来源冲突时：

```text
【证据冲突提示】
📜 本机构 SOP：[内容]（本地流程以此为准）
📋 现行指南：《[指南]》：[内容]
📖 教材：《麻醉护理学》：[内容]
⚠️ 差异说明：[差异点及原因分析]
```

---

## 硬规则

1. **5 步缺一不可**
2. **安全关键内容零容忍**——核验不过就不输出数值/流程
3. **冲突必须展示**，不得隐瞒或自动混合
4. **superseded 来源不能作为现行依据**
5. 试卷（assessment_sources）不得作为医学解释的证据
