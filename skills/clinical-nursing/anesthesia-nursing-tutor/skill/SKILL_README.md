# 麻醉护理学学习导师 Skill

> 基于综合教学模式（理论逐章 + 临床情景）的《麻醉护理学》学习导师，帮助护理学生和麻醉专科护士系统掌握围术期护理能力。

## 这是什么

一个为学习《麻醉护理学》（刘保江、晁储璋主编，人民卫生出版社）而设计的教学 Skill。融合了三个中医导师 Skill 的成熟骨架（水平评估、四步提问法、间隔重复、进度追踪、双向链接）与三个 GitHub 优秀教学项目的精华（learn-claude-code 的渐进课程锚点、DeepTutor 的可审计三层记忆、OATutor 的 BKT 知识追踪 + 三级脚手架）。

## 核心特色

| 设计支柱 | 说明 |
|:---|:---|
| 🔄 **围术期主循环锚点** | 所有知识都回归到主循环（术前评估→准备→诱导→维持→苏醒→恢复），每章只叠加一个新能力 |
| 📚 **教材为体，指南为用** | 《麻醉护理学》是理论根基，11 份围术期指南是临床决策最新依据，二者平等对照 |
| ⚠️ **安全第一** | 高危操作强制警示，高危章节（并发症/CPR）设硬掌握闸门 |
| 🎯 **L1-L4 分层教学** | 入门/进阶/实战/精通四个层级，不同层级不同教学策略 |
| 📊 **BKT 知识追踪** | 每个知识点量化掌握程度（M 值），最低掌握度优先复习 |
| 🪜 **三级脚手架** | 答错时逐步释放提示（提示→子题→兜底） |
| 🧠 **三层记忆** | L1 原始事件 → L2 提炼事实 → L3 学习者画像，任何结论可回溯 |
| 🔁 **间隔重复** | 1-3-7-14-30-60 课次，基于遗忘曲线 |
| 🔗 **双向链接** | 核心概念、药物、操作、并发症全部 Obsidian 双向链接 |

## 如何使用

### 触发 Skill

在 ZCode 对话中说以下任一短语即可触发：

- **"开始麻醉护理学习"** — 首次学习，会进行水平评估
- **"继续麻醉护理学习"** — 继续上次进度
- **"学习麻醉护理"** — 通用触发
- **"麻醉护理复习"** — 触发复习课
- **"开始麻醉护理测试"** — 单独进行水平评估测试

### 首次学习流程

1. AI 询问：快速评估（方式一，1 分钟）还是系统测试（方式二，15-20 分钟）
2. 完成 L1-L4 层级判定
3. （L3/L4 用户）询问是否固定关注某些指南视角
4. 从第一章开始（或根据已有基础跳到合适章节）
5. 按「要点展示→概念剖析→临床情景→四步提问→要点总结」流程学习
6. 课程结束保存笔记 + 更新进度

### 学习节奏

采用 10 节一单元的结构：
```
3 学 → 1 复 → 3 学 → 1 复 → 1 学 → 1 综合复习
```

## 教材结构（六篇二十二章）

本 Skill 覆盖完整教材，分三阶段渐进学习：

### 第一阶段：基础阶段（建立主循环认知锚点）
- 第一篇 绪论（第 1-3 章）：学科发展、麻醉科建设、专科护士培养
- 第二篇 基础知识与技能（第 4-6 章）：围术期药物、液体管理、监测技术 ⭐⭐⭐⭐⭐

### 第二阶段：临床阶段（主循环核心，情景题密集）
- 第三篇 临床麻醉护理学（第 7-11 章）：术前访视、麻醉准备、气道管理、各类麻醉、并发症 ⭐⭐⭐⭐⭐

### 第三阶段：进阶阶段（扩展能力）
- 第四篇 重症医学护理学（第 12-15 章）：恢复室、重症技术、CPR ⚠️、脏器功能不全
- 第五篇 疼痛诊疗护理学（第 16-18 章）：疼痛概述、分类评估、治疗护理
- 第六篇 麻醉护理管理（第 19-22 章）：药品管理、感染管理、仪器设备、信息管理

## L1-L4 层级与教学策略

| 层级 | 判断依据 | 教学策略 |
|:---|:---|:---|
| **L1 入门** | 无临床经验，药理/操作陌生 | 选项引导为主，每个术语自动解释，详细讲解 |
| **L2 进阶** | 学过教材理论，能做简单评估 | 开放提问为主，关键术语解释，减少提示密度 |
| **L3 实战** | 有临床实习经验，能独立做护理计划 | 讨论式教学，开放性问题，追问决策理由 |
| **L4 精通** | 麻醉专科护士，能处理复杂并发症 | 平等讨论，反向提问，多视角对比 |

## 重要说明

- **安全免责**：本 Skill 是教学辅助工具，所有药物剂量和操作流程仅供参考，临床应用必须遵医嘱并核对权威来源
