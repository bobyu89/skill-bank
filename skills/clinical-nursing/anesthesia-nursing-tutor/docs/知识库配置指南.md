# 知识库配置指南

> 本指南教你如何配置 Skill 的知识库路径，以及如何扩展知识库（接入试卷题库、基础医学教材等）。

---

## 一、零配置情况（推荐新手）

本仓库已内置完整知识库：

```
anesthesia-nursing-tutor/
└── knowledge_base/
    ├── textbook/
    │   └── 13578526_《麻醉护理学》.pdf_by_PaddleOCR-VL-1.6.md   # 教材
    └── guidelines/                                               # 13份指南
        └── *.pdf
```

**路径说明**：SKILL.md 中使用 `./knowledge_base/...` 相对路径。这要求 AI 运行时的工作目录在仓库根。

### ⚠️ 重要：建议改成绝对路径

ZCode/Claude Code 的 Skill 在不同项目中调用时，工作目录可能是任何地方。为确保稳定，**强烈建议**把 `./` 改成你 clone 后的**绝对路径**。

#### Windows 示例

假设你把仓库 clone 到 `F:\Users\你的用户名\Desktop\anesthesia-nursing-tutor`：

打开 `skill/SKILL.md`，找到「完整文件路径」段，改成：

```
核心教材：F:/Users/你的用户名/Desktop/anesthesia-nursing-tutor/knowledge_base/textbook/13578526_《麻醉护理学》.pdf_by_PaddleOCR-VL-1.6.md
围术期指南目录：F:/Users/你的用户名/Desktop/anesthesia-nursing-tutor/knowledge_base/guidelines/
```

> 💡 **提示**：Windows 路径建议用正斜杠 `/`，避免 Markdown 中 `\` 被转义。

#### macOS / Linux 示例

```
核心教材：/Users/你的用户名/Desktop/anesthesia-nursing-tutor/knowledge_base/textbook/13578526_《麻醉护理学》.pdf_by_PaddleOCR-VL-1.6.md
围术期指南目录：/Users/你的用户名/Desktop/anesthesia-nursing-tutor/knowledge_base/guidelines/
```

同样地，`skill/agent_prompt.md` 末尾的「知识库路径配置」段也要同步修改。

## 二、笔记目录配置

默认情况下，学习笔记和进度文件保存在仓库根的 `notes/` 目录：

```
笔记目录：./notes/麻醉护理学/
进度文件：./notes/麻醉护理学/进度追踪.md
```

### 改成其他位置

如果你想保存在别处（例如专门的笔记库），修改 `skill/SKILL.md` 的「笔记保存位置」段：

```
学习笔记目录：F:/你的笔记库/麻醉护理学/
进度追踪文件：F:/你的笔记库/麻醉护理学/进度追踪.md
```

`skill/agent_prompt.md` 中「第一步：读取学习进度」的默认路径也要同步修改。

> 📌 `notes/` 已在 `.gitignore` 中排除，你的私人学习数据不会被提交。

## 三、扩展知识库（可选）

如果你想接入更多资料，增强学习效果：

### 1. 试卷题库（用于生成情景题和测验）

如果你有麻醉护理学试卷（docx/json/md），可以接入：

```
你的试卷库目录/
├── exam_2026/           # 本科期末试卷
├── intval_n2/           # N2级试卷
├── extval_n3n4_head/    # N3-N4试卷
└── hard100/             # 高难度100题
```

修改 `skill/SKILL.md` 的「可选扩展」段，把 `[用户指定]` 替换为你的实际路径。

### 2. 基础医学教材（用于理论溯源）

如果想在做药理/生理机制分析时溯源到基础教材，可以接入：

```
你的基础教材切片目录/
├── textbook_cleaned_internal_medicine.md      # 内科学
├── textbook_cleaned_systematic_anatomy.md     # 系统解剖学
└── textbook_cleaned_physiology.md             # 生理学（需自行OCR）
```

### 3. 高难度选择题（用于 L3-L4 训练）

```
你的题目文件/麻醉护理学高难度单项选择题100道.md
```

修改 `skill/SKILL.md` 中对应行的路径即可。

## 四、添加更多围术期指南

如果你想补充指南：

1. 把 PDF 放到 `knowledge_base/guidelines/`
2. 在 `skill/SKILL.md` 的「已知围术期指南清单」表中添加一行：

```
| [指南名称] | [主题] | [对应教材章节] |
```

3. 在 `skill/agent_prompt.md` 的「已知围术期指南与教材章节对应」表中也添加对应行

## 五、故障排查

### Q1：AI 说"知识库中暂无此内容"，但文件确实存在？

- 检查路径是否正确（特别是中文文件名、特殊字符如《》、空格）
- Windows 路径用正斜杠 `/` 而非反斜杠 `\`
- 确认 AI 运行时的工作目录，必要时用绝对路径

### Q2：教材 md 中的图片显示不出来？

教材 md 中的图片是 PaddleOCR 在线 URL（带鉴权 token），可能会过期。这不影响文本学习，只影响图片显示。如需图片，建议自行 OCR 原版 PDF。

### Q3：指南 PDF 是扫描版，AI 读取不到内容？

部分指南 PDF 可能是扫描版无文本层。AI 读取 PDF 时如果取不到文本，可以：
- 用 OCR 工具（如 PaddleOCR、MinerU、Docling）先转成 md/txt
- 或在对话中告诉 AI 该指南的具体内容

### Q4：路径配置正确但仍报错？

打开 ZCode/Claude Code 调试模式，确认 Skill 实际读取的是哪个 SKILL.md 文件——你可能在全局 skills 目录和项目本地 skills 目录都有副本，改了一个但生效的是另一个。

## 六、配置检查清单

完成配置后，对照检查：

- [ ] `skill/SKILL.md` 中核心教材路径正确（绝对路径）
- [ ] `skill/SKILL.md` 中围术期指南目录路径正确
- [ ] `skill/SKILL.md` 中笔记目录路径正确（或保留默认 `./notes/`）
- [ ] `skill/agent_prompt.md` 中路径与 SKILL.md 一致
- [ ] Skill 已正确安装到 ZCode/Claude Code 的 skills 目录
- [ ] 在对话中说「开始麻醉护理学习」能正常触发

如有问题，提 [Issue](https://github.com/your-username/anesthesia-nursing-tutor/issues)。
