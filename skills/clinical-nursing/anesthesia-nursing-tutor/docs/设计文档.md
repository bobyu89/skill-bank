# 设计文档

> 本文档说明 Anesthesia Nursing Tutor Skill 的设计理念、教学理论依据，以及各项设计的灵感来源。适合想理解"为什么这样设计"或想二次开发的用户阅读。

---

## 一、设计目标

帮助护理学生和麻醉专科护士**系统掌握围术期护理能力**，核心培养目标是：
1. **安全意识**——高危操作的识别与应急
2. **临床决策能力**——基于评估做出护理决策
3. **理论系统性**——教材知识网络化、长期记忆

适用场景：护理本科期末备考、麻醉专科护士规范化培训、职称晋升。

---

## 二、五大设计支柱

### 支柱 1：围术期主循环锚点

**理念**：整个围术期护理围绕一个不变的主循环展开，每学一章只叠加一个新能力。

```
术前评估 → 麻醉前准备 → 麻醉诱导 → 麻醉维持 → 术毕苏醒 → 术后恢复/随访
     ↑                                                          │
     └──────────────── 反馈与改进 ←──────────────────────────────┘
```

**理论依据**：
- **认知负荷理论**（Sweller）——每章只加一个新机制，控制外在认知负荷
- **图式理论**——主循环是大图式，每章是子图式，逐步建构

**灵感来源**：[learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) 的「不变量地基 + 每课只加一个新机制」设计。

**落地**：教材 22 章按主循环环节归类，每章开头用 `📍 本章在围术期主循环中的位置：【XX】环节` 标注。

---

### 支柱 2：教材为体，指南为用

**理念**：
- 《麻醉护理学》教材（2013）是**理论根基**——所有知识的源头
- 围术期指南/共识是**临床决策最新依据**——教材可能滞后于指南更新
- 二者关系类似中医「内经为体，六经为用」

**冲突处理原则**：
- 当教材与指南冲突时（如 CPR 流程、血压管理目标），**以最新指南为准**
- 但提醒学习者"考试时以教材为准，临床中以指南为准"

**落地**：每个情景题反馈都用「📖 教材 vs 📋 指南 vs 🏥 临床」三视角对照。

---

### 支柱 3：L1-L4 分层教学

**理念**：不同水平的学习者用不同的教学策略。

| 层级 | 教学策略 |
|:---|:---|
| L1 入门 | 选项引导、术语自动解释、详细讲解 |
| L2 进阶 | 开放提问、关键术语解释、减少提示 |
| L3 实战 | 讨论式、开放性、追问决策理由 |
| L4 精通 | 平等讨论、反向提问、多视角对比 |

**理论依据**：
- **最近发展区（ZPD）**（Vygotsky）——教学应略高于当前水平
- **掌握学习**（Bloom）——学透了再前进

**灵感来源**：中医温病/伤寒杂病论学习导师 Skill 的 L1-L4 系统。

---

### 支柱 4：BKT 知识追踪 + 三级脚手架

#### BKT（贝叶斯知识追踪）

**理念**：为每个知识点（KC）量化掌握程度，指导复习选题。

**简化参数**：
- 掌握概率 M（0-1）：初始 0.5
- 答对：M = M + (1-M) × 0.3
- 答错：M = M × 0.4
- M<0.3 薄弱；M>0.85 掌握

**复习选题**：综合复习时优先选 M 最低的 KC（最低掌握度优先）。

**灵感来源**：[OATutor](https://github.com/CAHLR/OATutor) 的 BKT 四参数系统。本 Skill 做了简化（去掉 Slip/Guess 参数，因为 Skill 不需要严格的概率推断）。

#### 三级脚手架

**理念**：答错时逐步释放提示，而不是直接给答案。

| 级别 | 类型 | 说明 |
|:---|:---|:---|
| 1 | Hint 提示 | 纯文字引导，不要求输入 |
| 2 | Scaffold 脚手架 | 拆成子题，要求输入 |
| 3 | Bottom-out 兜底 | 直接给答案 + 解释 |

**理论依据**：**渐进式脚手架**（faded scaffolding）——逐步撤除支持，培养独立能力。

**灵感来源**：OATutor 的 Hint/Scaffold/Bottom-out 三级体系。

---

### 支柱 5：三层可审计记忆

**理念**：学习记录分三层，任何画像级结论都能回溯到原始事件。

| 层级 | 内容 | 存储位置 |
|:---|:---|:---|
| L1 原始事件 | 每次答题的原始记录（题目、答案、对错） | 进度文件"学习记录"表 |
| L2 提炼事实 | 按章节提炼的"该生常错的 KC"、错误模式 | 进度文件"BKT 知识追踪表" |
| L3 学习者画像 | 跨章节综合（如"药理学薄弱""气道管理扎实"） | 进度文件"学习者画像"段 |

**核心原则**：画像中没有任何主张是无法追溯的——任何 L3 结论都能回溯到 L1 原始事件。

**灵感来源**：[DeepTutor](https://github.com/HKUDS/DeepTutor) 的 L1/L2/L3 三层文件记忆系统。

## 三、四步提问法

每节内容围绕四步提问展开：

| 步骤 | 目的 | 理论依据 |
|:---|:---|:---|
| 1. 定义题 | 检测概念理解 | 布卢姆认知层次：记忆/理解 |
| 2. 应用题 | 情景应用 | 布卢姆认知层次：应用/分析 |
| 3. 反向提问 | 鉴别训练，防误导 | 批判性思维、概念改变理论 |
| 4. 自由发散 | 拓展知识面 | 建构主义、自主学习 |

**灵感来源**：中医伤寒杂病论学习导师 Skill 的四步提问法。

## 四、间隔重复系统

**复习间隔**（以课次为单位）：

| 复习次数 | 间隔 |
|:---|:---|
| 第1次 | 1 课次 |
| 第2次 | 3 课次 |
| 第3次 | 7 课次 |
| 第4次 | 14 课次 |
| 第5次 | 30 课次 |
| 第6次及以后 | 60 课次 |

**理论依据**：**艾宾浩斯遗忘曲线**——按记忆衰减规律安排复习。

**创新点**：以"课次"为单位而非"自然日"，因为学习者可能不是每天学，这样更灵活。

**高危知识点强制纳入**：恶性高热、局麻药中毒、过敏休克、CPR 等即使未到期也强制回顾。

## 五、安全设计

麻醉护理涉及大量高风险操作，**安全是第一原则**。

### 高危警示机制

涉及以下内容时强制用 `⚠️ 高危警示：` 标注：
- 恶性高热（MH）——触发药物、早期识别、丹曲林
- 局麻药中毒（LAST）——毒性反应、脂肪乳剂
- 过敏休克——分级处理、肾上腺素
- 困难气道/气管插管——Mallampati 评估、插管失败预案
- 全脊麻/高位脊麻——椎管内麻醉严重并发症
- 心搏骤停/CPR——最新流程
- 术后呼吸抑制——阿片类药物不良反应

### 硬掌握闸门

高危章节（第十一章并发症、第十四章 CPR、第十五章脏器功能不全）必须通过关键知识点测试才能进入下一章。

**灵感来源**：DeepTutor 的 per-type mastery gate。

## 七、中医 Skill 的借鉴

本 Skill 的成熟骨架来自中医学习导师 Skill 系列：

| 借鉴点 | 来源 Skill |
|:---|:---|
| L1-L4 分层系统 + 多学派分析 | 中医温病课程导师 |
| 四步提问法 + 综合复习三步流程 | 中医伤寒杂病论学习导师 |
| 字词溯源思路（本 Skill 改为概念剖析） | 中医黄帝内经学习导师 |
| 间隔重复系统（1-3-7-14-30-60） | 三者通用 |
| 进度追踪 + 三层记忆 + 双向链接 | 三者通用 |

**核心改造**：中医 Skill 是"哲学/临床"学习，本 Skill 是"理论+操作"学习，因此：
- 去掉字词溯源（《说文解字》对麻醉学无意义）
- 去掉哲学关联（周易/淮南子）
- 增加：高危警示、硬掌握闘门、临床情景题、BKT 知识追踪、三级脚手架

## 八、文件结构说明

```
skill/
├── SKILL.md                # 主指令：核心原则、学习流程、知识库规范、实现步骤
├── agent_prompt.md         # Agent 执行流程：读进度→评估→教学→更新
├── 水平评估测试.md          # L1-L4 四模块递进测试（独立调用）
├── 学习进度追踪_模板.md     # 进度模板（含 BKT/三层记忆/间隔表）
└── SKILL_README.md         # Skill 内部说明
```

**设计原则**（Anthropic Skills 规范）：
- **渐进式披露**：SKILL.md 是主入口（<1000 行），细节分散到其他文件
- **关注点分离**：主指令、执行流程、测试、模板各自独立
- **YAML frontmatter**：description 字段是触发机制，写得"积极"（pushy）以提高触发率

## 九、二次开发建议

如果你想改造本 Skill 用于其他医学教材学习：

1. **替换教材**：把 `knowledge_base/textbook/` 下的 md 换成你的教材
2. **改章节结构**：修改 SKILL.md 的「教材学习顺序」表
3. **改指南清单**：修改「已知围术期指南清单」表
4. **改核心概念双向链接**：修改 SKILL.md 的「必须使用双向链接的核心概念」段
5. **改水平评估测试**：修改 `水平评估测试.md` 的题目

**适用领域**：内科学、外科学、妇产科学、儿科学、急危重症护理学等其他医学护理教材。
